    Python API¶

    import factlang as fl

    Everything in fl.__all__ is public API, and so is the __all__ of each public package: fl.ir, fl.sql, fl.connectors, fl.types, fl.syntax (factlang.syntax) and factlang.agent. Import from those paths; any other module path (factlang.semantics.…, factlang.ir.primitives, factlang.connectors.base, …) is internal and may move. The package follows SemVer from 0.1.0; the language itself is versioned separately (fl.LANGUAGE_VERSION == "1.0").

    Stable API¶

    The following are public API under SemVer: no breaking change within a 0.x minor series. Libraries built on FactLang, schema profilers in particular, may depend on them.

    item
    factlang.ir primitives (ColumnAggregate, CompositeKeyAggregate, ValueMembership, KeyOverlap, PatternCoverage, MetadataQuery), their fields and result columns, Metric, SampleSpec IR primitives
    Checker.measure, Checker.ameasure, Checker.estimate, fl.measure, Measurement, CostEstimate Raw measurement
    fl.parse_filter, fl.sql.render_filter, fl.sql.render_join, RenderedFragment Fragments
    fl.connectors.run_metadata (also fl.run_metadata) Metadata SQL
    fl.Ident, fl.TableRef, fl.ColumnRef, fl.EdgeRef (also in fl.ir) IR primitives
    fl.check_pack, fl.Catalog (the catalog protocol) Packs, Catalogs
    fl.discover_packs(): {name: factory} for every pack installed under the factlang.packs entry-point group Packs
    fl.types.LiteralKind, fl.types.ValueType, fl.types.register_type (also importable as from factlang.types import …) Value types
    fl.sql.Param (a typed bind parameter) Fragments
    fl.connectors.Connector, AsyncConnector, QueryResult, ExecutionError Connectors
    factlang.syntax.FILTER_KEYWORDS: the words reserved inside a WHERE filter (the filter-keyword set only, not every keyword of the language) Filters
    factlang.syntax.needs_quoting, factlang.syntax.quote_name: whether a name must be quoted in FactLang source, and its quoted form Writing names from code
    fl.ir.register_primitive, fl.ir.unregister_primitive (fl.ir.PRIMITIVE_LOWERINGS is read-only by convention: change it only through these two) IR primitives
    Report.verified and Report.ok Verdicts

    The metric aliases (row_count non_null distinct_keys max_rows_per_key min_value max_value sum_value avg_value duplicate_keys server_now) are a wire format and do not change at all.

    One-call helpers¶

    lint ¶

    lint(text: str, *, pack: ContractPack | None = None, catalog: Catalog | None = None) -> DiagnosticBag

    Every front-end diagnostic of text (parse + analysis); never executes anything.

    The bag remembers text, so fl.lint(text).render() prints caret diagnostics.

    format ¶

    format(text: str) -> str

    The canonical form of text. Raises ValueError (with the rendered diagnostics) when text does not parse: formatting it would silently drop the broken lines.

    compile ¶

    compile(text: str, *, dialect: str, pack: ContractPack | None = None) -> list[RenderedProbe]

    Each claim's own probe for dialect, in source order, without a warehouse.

    Unprobeable (semantic) claims have no SQL and are skipped. Any invalid claim, or a claim that cannot be rendered for dialect, raises ValueError naming every such claim and its diagnostic codes.

    check ¶

    check(text: str, *, connector: Connector | AsyncConnector, **checker_kwargs: Any) -> Outcome | Report

    Check text on connector: the Outcome when it holds exactly one claim, else the Report. checker_kwargs go to :class:~factlang.engine.Checker.

    measure ¶

    measure(plans: ProbePlan, *, connector: Connector | AsyncConnector, **checker_kwargs: Any) -> Measurement

    measure(plans: Sequence[ProbePlan], *, connector: Connector | AsyncConnector, **checker_kwargs: Any) -> list[Measurement]

    measure(plans: ProbePlan | Sequence[ProbePlan], *, connector: Connector | AsyncConnector, **checker_kwargs: Any) -> Measurement | list[Measurement]

    Run IR primitives with no claim (R1, B3): one plan gives one Measurement, a sequence of plans a list (fused like Checker.measure). Never raises for a failure.

    parse_filter ¶

    parse_filter(text: str, *, catalog: Catalog | None = None, table: TableRef | None = None) -> tuple[FilterExpr | None, DiagnosticBag]

    Parse and analyse a bare spec 4.5 condition (R6), with or without a leading WHERE.

    Parameters are p1, p2, ... in source order. With a catalog and a table the columns are checked as in a claim. The filter is None when there is any error.

    parse ¶

    parse(source: str) -> ParseResult

    Tokenize and parse source; never raises.

    needs_quoting ¶

    needs_quoting(name: str) -> bool

    True iff writing name bare in FactLang source would not denote that exact name.

    A bare name must match [A-Za-z_][A-Za-z0-9_$]* (ASCII), must not be an uppercase word (at least one letter and no lowercase letter: such a word starts the attribute section or is read as a keyword) and must not be WHERE, USE or a member of FILTER_KEYWORDS (case-sensitive). deleted, Status and order need no quotes; ID, NULL, order items and 2fa do. Quoting is always safe: when in doubt (a non-ASCII letter, say) the answer is True.

    quote_name ¶

    quote_name(name: str) -> str

    The FactLang double-quoted form of name: " + name with " doubled + ".

    Raises ValueError for an empty name and for a name holding a carriage return or a newline (a quoted identifier cannot span lines) or NUL (no warehouse identifier can hold it; rendering would refuse it as FL502).

    fl.check with a single claim returns an Outcome; with any other number it returns a Report. To get document-level diagnostics (a broken USE line, for instance) always use Checker.check, which returns a Report.

    Report.verified is the flag to gate on: every outcome that is not UNPROBEABLE is PASS, there is at least one such outcome, and no error diagnostic was raised. Report.ok is weaker: it only rules out FAIL, ERROR and INVALID, so a report with NO_DATA outcomes, or with nothing measured at all, is ok but not verified.

    Checking¶

    Checker ¶

    Checker(connector: Connector | AsyncConnector | None = None, *, dialect: str | None = None, pack: ContractPack | None = None, catalog: Catalog | None = None, concurrency: int = 4, timeout_s: float | None = 60, max_bytes: int | None = None, fuse: bool = True, prefer: Prefer = 'native')

    Checks FactLang documents against one warehouse (spec 9.3).

    dialect defaults to the connector's. With a connector and no catalog, names are checked (and catalog verbs answered) through CachedCatalog(WarehouseCatalog(connector)) (spec 6.1). concurrency probes run at once (a thread pool; acheck an asyncio semaphore). max_bytes enables the dry-run cost guard (FL701). A connector that does not enforce timeout_s is backstopped: no answer TIMEOUT_GRACE_S after the timeout is FL702.

    check ¶

    check(text: str) -> Report

    Check every claim of text. Raises ValueError only when a rendered probe must run and the Checker has no connector (a configuration error, not a claim outcome).

    acheck async ¶

    acheck(text: str) -> Report

    compile ¶

    compile(text: str) -> list[RenderedProbe | Outcome]

    Each claim's own (unfused) probe, or its outcome when it has none; never executes.

    A catalog verb compiles to the MetadataQuery probe of its table.

    measure ¶

    measure(plans: Sequence[ProbePlan]) -> list[Measurement]

    Run raw IR primitives (R1); sampled plans allowed. Never raises for a failure.

    ameasure async ¶

    ameasure(plans: Sequence[ProbePlan]) -> list[Measurement]

    estimate ¶

    estimate(items: str | Sequence[ProbePlan]) -> list[CostEstimate]

    Dry-run prices of each probeable claim (text) or plan (R5). Never executes.

    Claims are analysed without a catalog (any catalog may execute metadata queries); invalid, unprobeable and catalog claims are skipped.

    offline_catalog ¶

    offline_catalog() -> Catalog | None

    The catalog to analyse with when nothing may be executed: the one the host gave, or None when this Checker built its own warehouse catalog (that one runs queries). Use it to build a sibling Checker for another dialect without touching the warehouse.

    Report dataclass ¶

    Report(outcomes: tuple[Outcome, ...], diagnostics: DiagnosticBag)

    Ordered outcomes of one document plus every diagnostic raised while checking it.

    ok property ¶

    ok: bool

    No FAIL, ERROR or INVALID outcome and no error diagnostic (e.g. a broken USE directive, which is not an outcome of its own).

    verified property ¶

    verified: bool

    Every claim that can be measured was measured and PASSed: no FAIL, ERROR, INVALID or NO_DATA outcome, no error diagnostic, and at least one outcome that is not UNPROBEABLE. Stricter than :attr:ok, which tolerates NO_DATA and a report with nothing measured (e.g. an empty document).

    to_dict ¶

    to_dict() -> dict[str, object]

    JSON-safe dict: Decimal -> str, temporals -> ISO-8601 (datetimes in UTC), tuples -> lists, enums -> their value.

    check_pack ¶

    check_pack(pack: ContractPack) -> list[str]

    Every completeness problem of pack (incl. inherited verbs), [] if none.

    Codes: FL600/FL601 (decide reads undeclared facts/attributes), FL602 (too few examples), FL603 (an example does not behave as declared, or its plan/catalog function raises), FL604 (an incomplete decorator-built contract; reported, never raised, and the other contracts are still checked), FL404 (a sampled plan), FL605 (a valid example with a WHERE whose plan drops the filter). Aliases are checked through their target.

    Within dataclass ¶

    Within(fact: str, attr: str, tolerance_attr: str = 'TOLERANCE', abs_attr: str = 'ABS_TOLERANCE')

    Answer verbs (spec 6.4): fact <op> claim[attr] with the claim's tolerance band.

    op is the operator the author wrote on attr (bare: ==). The band is max(TOLERANCE * |target|, ABS_TOLERANCE) over the attributes present (0 when neither is: exact, math.isclose when a float is involved). With a band b: == |a-t| <= b; != |a-t| > b; >= a >= t-b; > a > t-b; <= a <= t+b; < a < t+b. Arithmetic is in Decimal (a float via Decimal(str(x))).

    Connectors¶

    Connector ¶

    Bases: Protocol

    Executes rendered probes. dialect names a profile; paramstyle is the driver's.

    A connector may also define dry_run_bytes(probe) -> int | None (spec 18 R5): price a probe without executing it. It is optional; use :func:dry_run_bytes to call it.

    QueryResult dataclass ¶

    QueryResult(rows: list[dict[str, Any]] = list(), bytes_processed: int | None = None)

    ExecutionError ¶

    ExecutionError(message: str, *, code: str | None = None)

    Bases: Exception

    A probe (or metadata query) could not be executed; code is an FL7xx code.

    ExecutionError("FL702 timed out") takes the code from the message; ExecutionError("timed out", code="FL702") prefixes it. str(error) always starts with the code.

    run_metadata ¶

    run_metadata(connector: Connector, sql: str, params: Sequence[Param] | Mapping[str, object] = (), *, timeout_s: float | None = None) -> QueryResult

    Execute host-authored catalog metadata SQL through connector (spec 9.1, R8).

    sql marks bind parameters with neutral {{name}} tokens, exactly as a rendered probe does, and params supplies them (Param objects, or a {name: value} mapping whose families are inferred). They are bound with the connector's paramstyle, never spliced. The guard (:func:check_metadata_sql) runs first and raises ExecutionError FL703 before anything executes. Execution, timeouts and error mapping are the connector's own (FL700/FL702). This is not a claim: it yields rows, never an Outcome. The probe passed to the connector has plan=None, and the rows keep the labels the warehouse returned (no lower-casing).

    Through :class:~factlang.connectors.SQLAlchemyConnector, whose text() would read :word as a bind parameter even inside a string literal, every : in sql is escaped before binding, so literals such as 'a:b' and casts such as x::text reach the driver unchanged. A {{name}} token immediately after a : (x::{{t}}) cannot be bound by text(); neither can a token glued to a word character (a{{t}}, {{t}}b) or to another token ({{a}}{{b}}). SQLAlchemyConnector refuses those with FL700 before executing; separate them with a space.

    T-SQL (tsql or an alias such as mssql/sqlserver/synapse/fabric, and, failing closed, any dialect with no native profile), where statements may need no separator: only a SELECT is accepted, and it runs wrapped as SELECT * FROM (<sql>) AS fl_meta_q. So there is no WITH/SHOW, no ORDER BY without TOP (SQL Server rejects it in a derived table), every result column needs a distinct name, and no quote character may appear: no string literals and no quoted identifiers (' " [ ]); pass values, and compare odd names, as parameters.

    DBAPIConnector ¶

    DBAPIConnector(connection: Any, dialect: str, paramstyle: str | None = None)

    Executes probes on a PEP 249 connection.

    paramstyle defaults to the driver module's paramstyle (else qmark). Each probe runs on a fresh cursor, closed afterwards. With timeout_s the statement is cancelled through the cursor's interrupt()/cancel() (duckdb, pyodbc), else the connection's (sqlite3, psycopg), when the driver has one, and reported as FL702.

    Checker runs probes from several threads. Statements on one connection run concurrently only when that is safe: duckdb (cursor() is an independent duplicate connection), or a driver declaring PEP 249 threadsafety >= 2 whose cursors have their own cancel hook (trino). Otherwise they are serialised by one lock per connection object, shared by every connector wrapping it: a level-1 driver (pymysql, pyodbc; clickhouse-connect, which overstates its level) would interleave two statements, and with only a connection-level cancel (psycopg) one probe's timeout would cancel another's statement. Waiting for the lock counts against timeout_s; running out while waiting is FL702.

    CallableConnector ¶

    CallableConnector(fn: HostFn, dialect: str, paramstyle: str = 'qmark')

    Wraps fn(sql, params) -> rows; params is a tuple or dict per paramstyle.

    The host function cannot be given the timeout, so it is the host's to enforce; a TimeoutError (or any timeout-shaped error) it raises becomes FL702, any other exception FL700. An ExecutionError it raises passes through unchanged.

    StaticCatalog ¶

    StaticCatalog(tables: Mapping[str, Mapping[str, str]])

    Authoritative in-memory catalog keyed by dotted table key.

    Unquoted parts of a reference match case-insensitively; a quoted part matches exactly. The fullest key is tried first (catalog.schema.table, then schema.table, then table).

    CachedCatalog ¶

    CachedCatalog(inner: Catalog, ttl_s: float = 300, max_tables: int = 10000, clock: Callable[[], float] = time.monotonic)

    TTL + LRU cache over another catalog; None answers are cached too.

    Thread-safe: the cache is guarded by a lock, which is not held while the inner catalog is asked (two threads missing the same entry may both ask; the later answer is kept).

    WarehouseCatalog ¶

    WarehouseCatalog(connector: Connector, *, timeout_s: float | None = None, memo_s: float = 60.0, clock: Callable[[], float] = time.monotonic)

    Answers table_exists/columns from the warehouse's own catalog.

    An empty answer means the table does not exist (False). When the question cannot be asked or answered (rendering fails, the query fails with FL700, rows lack column_name/data_type) the answer is None (unknown), never False; the error is kept in :attr:errors. columns is also None when the dialect has no native profile, as its type names cannot then be mapped to families.

    A timeout (FL702) is not an answer: it is raised, so a caching wrapper does not store a transient failure as "unknown" for its whole TTL.

    One query serves one table_exists and one columns call for the same ref: the result is memoised until the other method has used it, or for at most memo_s seconds, so table_exists followed by columns (as CachedCatalog asks) costs one query. The memo is guarded by a lock, so one instance may serve several threads.

    native_columns ¶

    native_columns(ref: TableRef) -> dict[str, str] | None

    {column name: native type} (empty when the table does not exist), or None.

    Always queries; it does not use or fill the memo.
